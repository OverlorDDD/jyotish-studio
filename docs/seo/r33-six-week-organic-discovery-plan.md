# Galaxiora — 6-week organic discovery and authority experiment (start AFTER R3.3 release)

**This is a plan, not evidence of search demand or traffic.** Site owners should not pay for artificial backlinks or make invented Google review/author claims. Priority: Ukrainian long-tail calculator and Tarot informational intents, with English long-tail as secondary. Use actual Search Console data to refine.

## Sources and competitor opportunities

- Astro.com and Astro-Seek: rich specialist birth-chart tools. Counterstrategy: calculators + clear location/DST/ayanamsha methodology linked to learning pages.
- Drik Panchang: city-specific Vedic calendar. Counterstrategy: first-party sunrise-calculated Panchanga, exact transition moments, readable explanatory content; **no mass city doorway pages**.
- Tarot educational publishers (e.g. Labyrinthos, Biddy Tarot): deeply structured meanings and context. Counterstrategy: original curated guides with distinct situations, upright/reversed examples and links to real GalaxiTarot spreads; add further cards only after editorial review.
- Google brand/AI overview: the site's top organic result already exists, but AI overview once defined 'Galaxiora' incorrectly. Keep official About/Organization/site name and cultivate real public brand mentions/creator profiles only after accounts actually exist. No guarantee of AI answer correction.
- Google Discover: high-resolution original hero imagery is useful **later**, but no unverified third-party/watermarked stock art; test 1200+ px visuals after legitimate image ownership and design review.
- Google Search Central: helpful people-first content, not mass text or synthetic fake testimonials; original author and source transparency; canonical and hreflang; useful page experience.

## Six practical weekly blocks

| Week from release | Focus | Deliverable | Measurement |
|---|---|---|---|
| 1 | Indexation and brand trust | Verify sitemap after 20 new URLs (expected ~114); manually inspect 3 representative new URLs in GSC, check noindex/canonical/hreflang, use real first-party About/methodology links | Number of valid sitemap pages, technical errors |
| 2 | Tarot search cluster | Publish/confirm 8 original card detail pages + hub, add contextual links from Tarot, Academy; verify 78-card tool still works | Indexed canonical pages, clicks/impressions for card guide queries |
| 3 | NASA celestial calendar | Promote 2027 eclipse calendar from Panchanga; validate NASA global times and location caveats; write one genuinely useful city-focused explanatory example IF original calculation supports it | Search impressions 2027 and click-through from calendar to tool |
| 4 | Useful learning | Revisit original eight Academy lessons, improve weakest based on real query impressions; if no data, obtain independent SERP sample for proposed queries | Relevant nonbrand queries and article-to-tool clicks |
| 5 | Real community discovery | Establish official social accounts (user-controlled), give one free short educational visual demonstration per week; cite sources and link to relevant tool, no paid link farms | Tagged referral sessions, genuine follows, new calculator sessions |
| 6 | Learn and refine | Use Search Console query/page/country reports + analytics with consent; consolidate pages with overlap, prioritize 2–4 next originals; prepare R4 distribution roadmap | New vs returning visitors, registrations, tool use, nonbrand clicks |

**Traffic goals** are experiments, not promises. No 'rank #1' assertions. A new site may remain outside rankings initially even with perfect crawl. Search Console stats usually take time to appear; avoid false zero-traffic conclusions in the first day.

## Search Console and analytics events

- GSC Domain property is already verified. Only request manual indexing on a small representative set after release; sitemap resubmission every day is unnecessary.
- No birth date, birth time, birth city, email, Tarot question, user ID or private journal contents in analytics/UTM tags. Proposed coarse-grained events: `jyotish_calculation_started`, `jyotish_calculation_completed`, `panchanga_calculation_completed`, `tarot_spread_started`, `registration_completed`, `academy_lesson_opened`, `article_to_tool_click`. Instrument only after consent/privacy implementation and tested event handling.
- Report separate /uk vs /en query performance and separate branded vs nonbranded clicks. Don't compare raw impressions without target market/time.
- Preserve GA4/consent provider choice for a future owner action. Avoid inserting tracking scripts without consent review.

The immediate next turn should finish **R3.3 authority content release** only after green CI and AWS deployment. Then accept on actual sitemap health, major-module regression, verified bilingual article HTML, no restricted content exposure and Google URL Inspection status. Some Google indexing delay is expected and is not a same-day deployment defect.
